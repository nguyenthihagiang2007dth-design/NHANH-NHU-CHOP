# Nhanh Như Chớp - Hello Kitty Edition 🎀

Website trò chơi trí tuệ trực tuyến được lập trình bằng HTML, CSS và JavaScript nguyên bản với phong cách Kawaii Hello Kitty Pastel cực kỳ ngọt ngào!

## 🌟 Tính Năng Nổi Bật:
1. **Ngân Hàng 100 Câu Hỏi Tiếng Việt**: Chia làm 3 cấp độ (34 Dễ, 33 Trung bình, 33 Khó) kèm giải thích chi tiết.
2. **4 Chế Độ Chơi**: Dễ (100đ), Trung bình (200đ), Khó (300đ) và Thử thách tổng hợp.
3. **Điều Khiển Linh Hoạt**: Hỗ trợ Tạm dừng, Chơi lại và Thoát về trang chủ an toàn.
4. **Âm Thanh Sống Động**: Tích hợp Web Audio API phát âm thanh bấm nút, đúng/sai, đếm ngược tự động mà không cần tệp MP3 ngoài.
5. **Lưu Trữ Điểm Số**: Tự động lưu Kỷ lục & Bảng xếp hạng cá nhân vào LocalStorage.
6. **Chuẩn Responsive**: Giao diện hiển thị hoàn hảo trên cả máy tính, máy tính bảng và điện thoại cảm ứng.

## 🚀 Hướng Dẫn Chạy Website Bằng Visual Studio Code:
1. Giải nén tệp zip này vào một thư mục trên máy tính.
2. Mở **Visual Studio Code**.
3. Chọn **File -> Open Folder...** và chọn thư mục chứa tệp `index.html`.
4. Cài đặt tiện ích **Live Server** trong VS Code (nếu chưa cài).
5. Nhấp chuột phải vào tệp `index.html` và chọn **Open with Live Server**.

## 📱 Hướng Dẫn Kiểm Tra Trên Điện Thoại:
- Khi chạy bằng Live Server, mở Trình duyệt trên điện thoại và truy cập vào địa chỉ IP nội bộ của máy tính (ví dụ: `http://192.168.1.x:5500`).
- Hoặc mở trực tiếp tệp `index.html` bằng trình duyệt web trên điện thoại.
